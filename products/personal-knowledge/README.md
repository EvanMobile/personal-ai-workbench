# Personal Knowledge

## 产品定位

Personal Knowledge 是个人技术知识库，用于将原始信息逐步转化为结构化、可关联、可检索的知识资产。原始资料和整理后的知识资产需要区分，并保留来源与证据链。

## 核心目标

- 接收和保存原始知识来源（Raw Knowledge）。
- 通过 Capture、Digest、Link、Publish 工作流处理内容。
- 将整理后的知识资产（Curated Knowledge）结构化、关联、检索并持续维护。
- 保留原始资料，不以 Digest 结果覆盖原始来源。

## Raw Knowledge 与 Curated Knowledge

- **Raw Knowledge**：原始知识来源和资料，作为后续整理的输入与证据。应保持可追溯，不被整理结果覆盖。
- **Curated Knowledge**：经过整理的知识资产，可进一步结构化、关联、检索和维护。

二者应保持可追溯关系，使整理后的内容能够回到其来源和证据。

## Capture / Digest / Link / Publish

- **Capture**：接收并保存原始知识来源。
- **Digest**：在保留原始资料的前提下整理内容，形成知识资产。
- **Link**：建立知识资产之间以及资产与来源之间的关联。
- **Publish**：发布或呈现整理后的知识资产。

这些阶段描述内容处理方向，不预设具体工具、自动化程度或实现流程。

## 主要能力范围

- 保存和管理原始知识来源。
- 将原始内容整理为 Curated Knowledge。
- 对知识进行结构化和关联。
- 面向 Curated Knowledge 提供知识检索与持续维护能力。
- 保留来源和证据链，避免整理结果覆盖原始资料。

## 当前未决事项

- 来源证据链的具体表达和维护规则。
- 与其他产品的具体协作流程（尚未定义）。
