# Personal Arsenal

## 产品定位

Personal Arsenal 是个人工程武器库，用于持续沉淀和复用工程能力。它不只是代码片段收藏夹，而是面向可复用工程资产的独立产品。

## 核心目标

- 沉淀可复用的代码、脚本、工具和工程方法。
- 管理 Prompt、Agent、Workflow、Tool 等可复用能力。
- 支持能力的整理、检索、组合和调用。
- 形成可持续积累、整理和复用的个人工程能力资产。

## 主要能力范围

- 管理不同类型的工程资产和能力。
- 对资产进行整理和检索。
- 支持复用、组合与调用。
- 支持个人工程资产的持续积累。

以上为产品方向范围，不预设具体交互、执行机制或技术实现。

## 当前未决事项

- 工程资产的分类、描述规范和版本管理方式。
- Prompt、Agent、Workflow、Tool 等能力的边界及其关系。
- 能力组合、调用和运行的具体方式。
- 与其他产品的具体协作流程（尚未定义）。
