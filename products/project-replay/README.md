# Project Replay

## 产品定位

Project Replay 是一个历史工程项目的现代化重演平台。它以过去真实且具有工程意义的项目为对象，利用当下的技术重新审视原始问题，探索新的架构方案，并验证工程能力。

> 让过去积累的工程经验不再只存在于记忆中，而是通过现代技术重新实现，转化为可运行、可验证、可展示的工程资产。

**英文定义：**

> A modern reimplementation of historically significant engineering projects, using today's technologies to revisit original problems, explore new architectural approaches, and validate engineering capabilities.

Project Replay 不等同于普通项目管理工具，也不只是项目文档归档。重点是基于历史工程上下文进行现代化重新实现，并形成可以审查、运行、验证和展示的成果。

## 核心目标

- 恢复过去真实工程项目中的业务背景、技术决策和工程经验。
- 利用现代 AI 编程工具（例如 Codex）降低历史项目重新实现的成本。
- 结合当前技术体系，重新设计和实现过去的工程问题。
- 将长期积累的工程经验转化为可审查、可运行、可验证的工程成果。
- 通过项目重演实现技术练习、工程能力升级，并集中展示个人工程经验。

## 主要能力范围

- 恢复并整理历史项目的业务背景、原始问题、技术决策和工程经验。
- 基于当前技术和架构思路重新设计、实现历史工程问题。
- 借助现代 AI 编程工具辅助历史项目的理解与重新实现。
- 形成可审查、可运行、可验证、可展示的重演成果。
- 对比和审视原始方案与现代重演方案，从过程中练习和升级工程能力。

以上描述产品方向和能力范围，不预设具体交互、数据模型或技术实现。

## 当前未决事项

- 哪些历史项目适合纳入重演，以及项目案例的组织粒度。
- 历史资料的来源、整理方式和证据关联方式。
- 重演成果的审查、运行与验证标准。
- AI 编程工具在项目理解和重新实现中的具体使用边界与工作方式。
- 与其他产品的具体协作流程（尚未定义）。
